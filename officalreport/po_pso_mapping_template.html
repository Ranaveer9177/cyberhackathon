02 In-Depth Program Outcome Justifications

PO1: Engineering Knowledge & Mathematical Formulation Level 3

Apply mathematics, science, engineering fundamentals, and computing specialization to the solution of complex engineering problems.

How VibeGuard Addresses PO1: VibeGuard applies computer systems engineering principles: operating system process virtualization, memory-safe compiled systems programming in Rust, and Git Directed Acyclic Graph (DAG) commit traversal. The risk evaluation engine incorporates a deterministic mathematical model: RiskScore = max(0, 100 - (15 × Critical + 8 × High + 3 × Medium + 1 × Low)), ensuring a quantitative threshold for push gate blocking.
PO2: Problem Analysis & Shift-Left Paradigm Level 3

Identify, formulate, review research literature, and analyze complex engineering problems reaching substantiated conclusions.

How VibeGuard Addresses PO2: The team analyzed why enterprise secret management repeatedly fails in production: traditional cloud CI scans occur after commits are pushed, by which point secrets are permanently recorded in distributed Git logs. VibeGuard formulates an autonomous pre-push barrier that halts vulnerability propagation at the exact boundary of origin.
PO3: Design & Development of Solutions Level 3

Design solutions for complex engineering problems and design system components or processes that meet specified needs.

How VibeGuard Addresses PO3: Engineered a dual-engine architecture: (1) Go CLI coordinator managing hook lifecycles, Git archive extraction, and OSV REST networking; and (2) Rust high-speed worker scanning ASTs and token regexes. Designed a fail-closed gate ensuring push aborts if either binary is missing or if risk exceeds threshold.
PO4: Investigations of Complex Problems Level 3

Use research-based knowledge and research methods including design of experiments, analysis and interpretation of data.

How VibeGuard Addresses PO4: During Windows testing, standard CLI pipe redirection caused deadlocks on large git archives. The team conducted empirical experiments, proving that disk-staged pure Go archive/tar processing eliminated OS pipe buffer blocks. Further benchmarked serial vs concurrent OSV lookups, reducing query time from 8.2s to 420ms.
PO5: Modern Tool Usage Level 3

Create, select, and apply appropriate techniques, resources, and modern engineering and IT tools.

How VibeGuard Addresses PO5: VibeGuard integrates modern toolchains: Go 1.21+ toolchain, Rust Cargo compiler, MSVC toolset, Git internal hook subsystem, Google OSV API, and PowerShell system configuration scripts.
PO8: Professional Ethics & Data Privacy Level 3

Apply ethical principles and commit to professional ethics and responsibilities and norms of engineering practice.

How VibeGuard Addresses PO8: Guarantees absolute client-side code confidentiality. Proprietary source code is never transmitted to external clouds; only anonymized package metadata queries the OSV API. Discovered secrets are masked in memory (first 8 characters followed by ****) before output generation.
